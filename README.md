# Machine Learning based Buyer Segmentation and Investment Profiling for Real Estate Market Intelligence

**Collaborating Organizations:** Unified Mentor & Parcl Co. Limited  
**Domain:** Financial Analytics & Real Estate Market Intelligence  

## Project Overview
This project introduces AI-driven buyer intelligence into the Parcl real estate platform. By applying unsupervised machine learning algorithms (K-Means Clustering), this system identifies hidden customer segments and reveals diverse investment behaviors. The resulting insights enable Parcl to pivot away from generic property recommendations and build highly targeted, data-driven marketing strategies.

## Repository Structure
This project utilizes an industry-standard multi-file architecture to separate the heavy data processing from the live web application:

* **`ml_pipeline.py`**: The core data science script. It performs data cleaning, missing value imputation, feature encoding (One-Hot/Label), standard scaling, and trains the K-Means clustering model. 
* **`app.py`**: The interactive Streamlit dashboard. It reads the pre-processed data to provide real-time, high-speed visual analytics.
* **`requirements.txt`**: A list of required Python libraries to ensure a stable execution environment.
* **`clients.csv`**: The raw, input dataset containing buyer demographics, loan behaviors, and geographic data.
* **`clustered_clients.csv`**: The output dataset automatically generated by `ml_pipeline.py`, which contains the final assigned buyer segments used by the dashboard.

## Setup and Execution Instructions

Please follow these steps in order to replicate the environment and run the dashboard locally.

### 1. Install Dependencies
Ensure you have Python installed, then install the required libraries:


pip install -r requirements.txt


### 2. Run the Machine Learning Pipeline
Before launching the dashboard, you must process the raw data and generate the customer clusters. Run the pipeline script:

python ml_pipeline.py

*Note: You should see a success message indicating that `clustered_clients.csv` has been generated.*

### 3. Launch the Streamlit Dashboard
Once the data is clustered, start the live interactive web application:

streamlit run app.py

This will automatically open the dashboard in your default web browser (typically at `http://localhost:8501`).

Troubleshooting on Windows:
If you encounter streamlit : The term 'streamlit' is not recognized..., run the app directly through Python:

python -m streamlit run app.py
(Or use py -m streamlit run app.py if using the Python Launcher).

The web dashboard will automatically open in your default browser at http://localhost:8501.
## Dashboard Features
The resulting Streamlit application fulfills all PRD specifications, including:
1. **Buyer Segmentation Overview:** A visual breakdown of the four discovered buyer types (Global Investors, First-Time Buyers, Corporate Buyers, Luxury Investors).
2. **Investor Behavior Dashboard:** Comparative analysis of property acquisition purposes across different clusters.
3. **Geographic Buyer Analysis:** Regional mapping of where specific investor profiles are distributed.
4. **Segment Insights Panel:** Descriptive statistics (average age, total clients, average satisfaction) isolated by segment.
